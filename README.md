# スマホ使用時間減少＋読書推進アプリ（Reading Tree）

卒業論文研究において開発した、スマートフォンの使用時間を抑制しつつ読書習慣を定着させるための支援Webアプリケーションです。

---

## 🔗 公開URL（デモ）
- **WebアプリURL:** https://veltalto.github.io/reading-tree/
- PCおよびスマートフォンのブラウザからアクセスして利用できます。

---

## 📖 研究概要・アプリの目的
- **背景・課題:** （例：スマートフォンの長時間利用による読書離れの課題）
- **アプローチ:** （例：読書時間を記録・可視化し、木が育つなどのゲーミフィケーションを取り入れることで継続的な動機づけを行う）

---

## 🛠 技術スタック
- HTML5 / CSS3 / JavaScript (Vanilla JS)
- ホスティング: GitHub Pages

---

## 📱 主な機能・使い方
1. **タイマー / 読書記録:** 読書時間を計測・入力します。
2. **成長システム:** 読書量に応じて木やキャラクターが反応します。
3. （その他の機能があれば箇条書きで追記）
